# study-agent-demo

## 项目简介

`study-agent-demo` 是一个中文学习任务管理器的前端演示项目。它把学生常见的复习、做题、纠错和规划行为整理成一个可点击、可保存、可回看的本地闭环流程。

当前版本是 v0.1 local closed-loop prototype，重点展示产品结构、交互流程、结构化输出格式和 localStorage 本地记录能力。

## 在线 Demo

在线体验地址：[https://study-agent-demo.vercel.app/](https://study-agent-demo.vercel.app/)

## 核心定位

项目定位是“题目驱动的中文学习任务管理器”：先用习题倒推需要复习的课件范围，再通过速懂、讲解、错题定位和期末复习规划形成持续迭代的学习闭环。

本项目目前不接入真实 AI，不解析 PDF，也不读取上传文件；所有生成内容都是基于前端规则和本地 mock 数据的演示结果。

## 五个学习模式

1. 习题导向筛选
2. 课件范围速懂
3. 单题讲解
4. 错题定位
5. 期末复习规划

## 当前 v0.1 已实现功能

- 五个学习模式卡片，可点击切换当前模式。
- 每个模式显示用途、输入内容、输出内容和下一步模式。
- 每次生成都会展示结构化 mock 结果。
- mock 结果固定包含：结论、事实、推断、建议、【不确定】、如何验证、建议下一步。
- 使用 localStorage 保存本地学习记录。
- 保存 AssistantRun、StudyTask、MasteryRecord。
- 在“错题定位”模式保存 MistakeRecord。
- 支持掌握度自评：0 到 4。
- 支持错题原因选择。
- 本地学习记录面板展示统计数据。
- 本地记录详情面板展示最近生成记录、下一步任务、错题记录和掌握度记录。
- 支持更新任务状态：待做、进行中、已完成。
- “期末复习规划”会基于本地任务、错题和掌握度记录生成规则式 mock 规划。
- 支持清空本地演示数据并重新创建“默认课程”。

## 当前不支持的能力

- 不支持后端服务。
- 不支持真实 AI 调用。
- 不支持 PDF 解析。
- 不支持文件上传。
- 不支持自动读取课件内容。
- 不支持自动验证课件、答案或考试范围。
- 不支持多用户账号、云同步或跨设备数据同步。

## 手动 QA 验收清单

- 首页能显示产品名、中文副标题和 v0 限制提示。
- 五个学习模式按闭环顺序显示。
- 点击任意模式卡片后，该卡片有明显选中状态。
- 详情面板会随所选模式切换。
- 每个模式都有不同的输入 placeholder。
- 点击“生成结构化结果”后，会显示 mock 结构化结果。
- 结构化结果包含七个固定字段：结论、事实、推断、建议、【不确定】、如何验证、建议下一步。
- 生成后“本地学习记录”数量立即更新。
- 刷新页面后，已保存的记录数量仍然保留。
- 在“错题定位”模式生成后，错题记录数量增加。
- 掌握度自评会保存到掌握度记录。
- 任务状态按钮可以切换为待做、进行中、已完成。
- 刷新页面后，任务状态仍然保留。
- “期末复习规划”在有本地记录时，会引用任务、错题和掌握度数据生成规则式 mock 规划。
- “清空本地演示数据”会弹出确认框，确认后清空本地记录并保留默认课程。
- `npm run build` 通过。
